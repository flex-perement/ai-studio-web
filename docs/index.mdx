# 🏢 AI Studio

AI Studio — экосистема для разработки с человеческими стандартами.

## Отделы

- 💼 **Reception** — приём задач
- 👔 **Board** — планирование
- 🎯 **HR** — управление ресурсами
- 💻 **Dev** — разработка
- 🔒 **Security** — безопасность
- ✅ **QA** — контроль качества
- 📈 **Growth** — масштабирование
- 🔬 **RnD** — исследования

## Быстрый старк

```bash
git clone https://github.com/flex-perement/ai-studio-web
cd ai-studio-web
npm install
npm run dev
```
